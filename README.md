# Cookie's Sheets: downloads

Windows builds of **Cookie's Sheets**, a Pathfinder 1st Edition character sheet with a level-up wizard, compendium and quick rules.

**[Download the latest release](https://github.com/laurmoe7/cookies-sheets-releases/releases/latest)**, unzip it anywhere and run `Cookie's Sheets.exe`.

Source code: https://github.com/laurmoe7/cookies-sheets
